# 実験データ統計分析レポート (高度な5ステップ分析)

このレポートは、実験データのロードマップに従って実行された詳細な統計分析の結果をまとめたものです。

## 分析ロードマップ
1. **【Step 1】前処理**：主観評価（VAS）の「個人内正規化」
2. **【Step 2】前提検証**：「球面性の仮定」のチェック
3. **【Step 3】主検定**：「二元配置反復測定分散分析（Two-Way RM-ANOVA）」
4. **【Step 4】事後検定**：「多重比較（Post-hoc Test）」による条件間の特定および読み込み時間別分析
5. **【Step 5】行動・心理分析**：「混合効果モデル（LMM）」によるメカニズム解明

---

## 【Step 1】前処理：主観評価（VAS）の「個人内正規化」

主観評価値（VAS）は被験者ごとに評価基準やスケールの使い方が異なる（個人内バイアスがある）ため、被験者ごとに平均0、標準偏差1とする**個人内正規化（Ipsative Standardization / Zスコア化）**を適用しました。これにより、被験者間の絶対値のズレを排し、純粋な条件間の差異を検出します。

正規化前後のデータ分布比較プロットを保存しました: `step1_normalization_comparison.png`  
※プロットでは、被験者ごとに異なる色で分布を示しています。正規化後は被験者の分布が平均0、分散1に揃っていることがわかります。

## 【Step 2】前提検証：「球面性の仮定」のチェック

反復測定分散分析（RM-ANOVA）を適用するにあたり、条件間の差の分散が均一であるという**「球面性の仮定（Sphericity Assumption）」**を満たしているかを検証するため、**Mauchlyの球面性検定（Mauchly's Test of Sphericity）**を実行しました。

Mauchlyの検定で $p < 0.05$（有意）となった場合は球面性の仮定が棄却されるため、**Greenhouse-Geisser (GG) 補正**を適用して自由度を調整し、F値およびp値を補正します。

### 指標: perceivedLoadingTime (Zスコア)
- **loaderType要因**:
  - 球面性の仮定が満たされるか: False
  - $\chi^2$値: 43.4502, 自由度: 20, p値: 3.3713e-03
- **simulatedLoadingTime要因**:
  - 球面性の仮定が満たされるか: True
  - $\chi^2$値: 0.4277, 自由度: 2, p値: 8.0748e-01

### 指標: discomfort (Zスコア)
- **loaderType要因**:
  - 球面性の仮定が満たされるか: True
  - $\chi^2$値: 24.7062, 自由度: 20, p値: 2.6001e-01
- **simulatedLoadingTime要因**:
  - 球面性の仮定が満たされるか: True
  - $\chi^2$値: 4.3303, 自由度: 2, p値: 1.1473e-01

### 指標: reliability (Zスコア)
- **loaderType要因**:
  - 球面性の仮定が満たされるか: True
  - $\chi^2$値: 32.3808, 自由度: 20, p値: 5.7083e-02
- **simulatedLoadingTime要因**:
  - 球面性の仮定が満たされるか: True
  - $\chi^2$値: 5.8968, 自由度: 2, p値: 5.2425e-02

※注: pingouinの `rm_anova` を用いた主検定では、交互作用項も含め球面性の仮定が棄却された場合、自動的にGreenhouse-Geisser補正されたp値（`p_GG_corr`）が計算されます。以下の主検定結果では自動補正を考慮した値を使用します。

## 【Step 5】行動・心理分析：「混合効果モデル（LMM）」によるメカニズム解明

実験デザイン（`loaderType`, `simulatedLoadingTime`）に加え、ユーザーの実際の**操作・行動指標（レイジクリック数、マウス移動距離、純タスク時間）**が、主観的評価（不快感や信頼度）にどのような影響を及ぼしているかを包括的に分析するため、**線形混合効果モデル（Linear Mixed Effects Model: LMM）**を構築しました。

- 被験者（`participant_id`）を**ランダム効果（ランダム切片）**として設定し、個人特有の回答基準のばらつきを吸収します。
- 固定効果には以下の変数を投入しました：
  - `loaderType`（質的変数。ローダー画面なしの `none` を基準とするダミー変数に変換）
  - `simulatedLoadingTime_sec`（秒単位の実際の待ち時間：連続変数）
  - `rageClicks_z`（全体で標準化したレイジクリック数：連続変数）
  - `mouseDistance_z`（全体で標準化したマウス移動距離：連続変数）
- これにより、異なるスケールの行動指標（クリック数 vs ピクセル数）が心理評価に与える影響力を、係数（標準化偏回帰係数に近い形式）の大きさで直接比較できます。
