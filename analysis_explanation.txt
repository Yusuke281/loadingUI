被験者データが増えた場合の分析手順と、各プログラムについてご説明します。

---
**新しい分析ワークフロー（被験者が複数いる場合）**
---

分析は以下の2ステップで行います。

**ステップ1: 全データの統合**
1.  各被験者の行動データとアンケートデータを、指定の命名規則に従ってこのフォルダに保存します。
    *   行動データ: `task_timings_p1.csv`, `task_timings_p2.csv`, ...
    *   アンケートデータ: `survey_p1.csv`, `survey_p2.csv`, ...
2.  コマンドラインで以下のコマンドを実行します。
    ```
    python consolidate_data.py
    ```
3.  これにより、すべての被験者のデータが `all_data.csv` という名前の一つのファイルに統合されます。

**ステップ2: 統合データで分析を実行**
1.  ステップ1が完了したら、次に以下のコマンドを実行します。
    ```
    python advanced_analysis.py
    ```
2.  `all_data.csv` が読み込まれ、全被験者のデータに基づいた分析が実行されます。
3.  結果は `advanced_analysis_results` フォルダに保存されます。

---
**各スクリプトの説明**
---

**1. データ統合プログラム: `consolidate_data.py`**

*   **目的:** フォルダ内にある複数の被験者データ（`task_timings_p*.csv` と `survey_p*.csv`）を検索し、それらを一つにまとめて `all_data.csv` を生成します。
*   **詳細:** スクリプトは、ファイル名から被験者IDを自動で識別し、データに `participant_id` 列を追加してから結合します。

**2. 分析プログラム: `advanced_analysis.py`**

*   **目的:** `all_data.csv` を読み込み、ご依頼いただいた3つの高度な分析を実行します。
    *   **相関分析**
    *   **重回帰分析**
    *   **二元配置分散分析（交互作用あり）**
*   **詳細:** 被験者が複数人になり、各条件のサンプル数が2以上になると、以前は実行できなかった**交互作用効果**の分析が自動的に実行されます。サンプル数が足りない場合は、以前と同様に主効果のみの分析にフォールバックするようになっています。

**3. 出力フォルダ: `advanced_analysis_results`**

*   `advanced_analysis.py` の実行結果（グラフ画像、統計サマリーテキスト）がこのフォルダに保存されます。
