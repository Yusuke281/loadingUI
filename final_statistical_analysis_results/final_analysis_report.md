# ローディングUI実験データ：最終統計分析レポート (決定版)

本レポートは、被験者データ（10名、総試行数210回）に対する、学術的厳密さと実務的UX意思決定を両立させた**「統合統計分析パッケージ」**の最終実行結果です。

## 分析ロードマップ
1. **【Step 1】前処理（個人内正規化）**：VAS主観評価値の個人バイアスの排除
2. **【Step 2】前提検証（球面性のチェック）**：RM-ANOVAの前提検証とGreenhouse-Geisser補正の適用要否判断
3. **【Step 3】主検定（二元配置RM-ANOVA）**：ローダー種類と待ち時間が心理指標に与える影響の全体的検証
4. **【Step 4】事後検定（多重比較）**：
   - **統計的厳密版**：対応のあるt検定 ＋ **Holm補正** (待ち時間別＆プール全体)
   - **実務的可視化版**：**TukeyのHSD法**による同時信頼区間の推定 (待ち時間別＆プール全体)
5. **【Step 5】行動・心理分析（混合効果モデル：LMM）**：個人差を制御したUI効果量と行動影響の定量推定

---

## 1. 【Step 1】前処理：主観評価（VAS）の「個人内正規化」

VAS評価値の個人特有の回答基準（甘さ・辛さ・評価の振れ幅）を取り除き、条件間の差を純粋に評価するため、被験者（`participant_id`）ごとに平均0、標準偏差1とする**個人内正規化（Zスコア化）**を心理指標に施しました。

正規化カラムを含む統合データシートを保存しました: `consolidated_normalized_data_10p.csv`  
正規化前後のデータ分布比較プロットを保存しました: `step1_normalization_comparison.png`

## 2. 【Step 2】前提検証：「球面性の仮定」のチェック

反復測定分散分析の適用前提である球面性の仮定（水準間の差の分散の均一性）を検証するため、**Mauchlyの球面性検定（Mauchly's Test of Sphericity）**を実行しました。有意（$p < 0.05$）となった場合、検定統計量のバイアスを防ぐため、主検定において**Greenhouse-Geisser (GG) 補正**を適用します。

- **loaderType要因** (水準数 7):
  - 球面性の仮定が満たされるか: False
  - $\chi^2$: 43.4502, dof: 20, p値: 3.3713e-03 (GG補正が必要)
- **simulatedLoadingTime要因** (水準数 3):
  - 球面性の仮定が満たされるか: True
  - $\chi^2$: 0.4277, dof: 2, p値: 8.0748e-01 (球面性を維持)

### 指標: discomfort (Zスコア)

- **simulatedLoadingTime要因** (水準数 3):
